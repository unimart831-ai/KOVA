## Crisis Management

### Social Media Crises Unimart Might Face

| Crisis | Detection | Response Strategy |
|--------|-----------|------------------|
| **Scam accusation** ("Someone got scammed on Unimart!") | Engage Agent flags negative sentiment spike | Immediate: Pause autopilot replies. Personal: Acknowledge, investigate, share safety features. Follow-up: Publish trust & safety thread. |
| **Platform outage** (unimartafrica.com goes down) | Direct complaints on social media | Acknowledge quickly on Twitter: "We know, we're on it. Back shortly." Don't hide it. Students respect transparency. |
| **Controversy** (e.g., inappropriate listing, offensive seller) | Engage Agent flags high-volume negative | Remove listing. Public statement. Show enforcement of community guidelines. |
| **Competitor attack** ("Unimart is just WhatsApp groups but worse") | Research Agent / Engage Agent | Don't attack back. Respond with data: "0.3% dispute rate, verified sellers, escrow payments. WhatsApp Groups = 0 protection." |
| **Negative press** | Research Agent trends / manual detection | Professional LinkedIn response. Data + vision. Don't be defensive. |

### Crisis Protocol When Using Kova

1. **Immediately:** Disable auto-engage for the affected platform (toggle off in Engage Agent settings)
2. **Within 30 minutes:** Draft a response (use Kova to generate options, but review carefully)
3. **Within 1 hour:** Publish official response on affected platform
4. **Within 24 hours:** Follow-up content addressing the root cause
5. **After resolution:** Re-enable auto-engage. Submit a seed about the improvement made.
