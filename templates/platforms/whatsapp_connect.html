Connect WhatsApp

WhatsApp uses a permanent access token from Meta Business Suite. Enter your System User token below to connect.

How to get your access token:

  1. Go to Meta Business Suite → Settings
  2. Navigate to Users → System Users
  3. Create or select a System User with Admin role
  4. Click "Generate New Token" for your WhatsApp app
  5. Select permissions: whatsapp_business_messaging and whatsapp_business_management
  6. Copy the generated token and paste it below

System User tokens don't expire. You can revoke access from Meta Business Suite anytime.
