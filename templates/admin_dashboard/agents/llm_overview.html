How Model Resolution Works

1

Per-Task Override

If a specific task (e.g. "create.generate") has a model override set, that model is used regardless of plan.

2

Plan-Specific Tier

If the user's plan (e.g. "agency") has models configured, use that plan's tier (premium/workhorse/fast).

3

Global Tier Default

Fall back to the global tier settings (Premium, Workhorse, Fast models configured above).

4

Fallback Chain

If the chosen model fails, try free fallback chain, then paid fallback (if enabled).
