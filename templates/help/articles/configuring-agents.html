Configuring Agent Behavior

Each agent can be customized with instructions, toggled on or off, and monitored for activity.

Accessing Agent Settings

  1. Go to Agents from the sidebar
  2. Click on any agent card to view its detail page
  3. From there, you can toggle the agent, add instructions, and see its activity log

Enabling / Disabling Agents

Each agent has a toggle switch. When disabled:

  • The agent stops running its scheduled tasks
  • No new actions are taken by that agent
  • Existing scheduled content is not affected

Tip: Start with the Create Agent and Research Agent enabled. Add others as you get comfortable.

Custom Instructions

You can give each agent specific instructions that shape its behavior. These are like "standing orders" the agent follows every time it runs.

Example instructions for the Create Agent:

  • "Always include a call-to-action at the end of posts"
  • "Never use emojis on LinkedIn posts"
  • "Use Kenyan English spelling and references"
  • "Focus on educational content over promotional"

Example instructions for the Research Agent:

  • "Focus on AI and SaaS industry trends"
  • "Prioritize trending topics from African tech ecosystem"
  • "Look for controversial takes I can respond to"

Agent Activity Log

Each agent's detail page shows a log of recent actions: what the agent did, when, and the result. This helps you understand what your agents are up to and spot any issues.

Token Usage

AI agents consume tokens (API calls) when they run. You can see token usage on each agent's detail page. Higher plans include more token allocation.
