Kova Pixel — Website Tracking

The Kova Pixel is a lightweight JavaScript snippet you add to your website. It tracks visitor behavior — page views, clicks, and conversions — and connects them back to your social media posts.

What It Does

  • Tracks page views — See which pages your social media audience visits
  • Measures conversions — Track purchases, sign-ups, or any custom event
  • Attribution — Links website activity back to the specific social post or platform that drove the visit
  • Revenue tracking — When you fire a conversion event with a value, Kova calculates your social media ROI

Setting Up the Pixel

  1. Go to Kova Pixel from the sidebar under Conversion
  2. Copy the pixel code snippet
  3. Paste it into the <head> section of your website (or use Google Tag Manager)
  4. The pixel starts tracking immediately — no configuration needed for basic page views

Tracking Custom Events

Beyond page views, you can track custom events like purchases or form submissions:

// Track a purchase
KovaPixel.track('purchase', { value: 2500, currency: 'KES' });

// Track a sign-up
KovaPixel.track('signup');

// Track a custom event
KovaPixel.track('added_to_cart', { product: 'Premium Plan' });

Viewing Results

Go to Kova Pixel settings to see:

  • Total events tracked
  • Unique visitors
  • Revenue attributed to social media
  • Top pages visited

How Attribution Works

When someone clicks a link from your social post, the Kova Pixel picks up UTM parameters automatically. It then connects that visitor's website activity back to the specific post and platform — so you can see exactly which social content drives real business results.
