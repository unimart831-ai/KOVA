Engagement Inbox

The Engagement Inbox is your unified view of comments and interactions across all connected platforms — available on the Pro plan and above.

How It Works

  1. The Engage Agent monitors your published posts for new comments
  2. Incoming comments appear in the Inbox with sentiment analysis (positive, neutral, negative)
  3. The agent drafts suggested replies based on context
  4. You can approve the suggested reply, edit it, or write your own

Sentiment Analysis

Each comment is analyzed for sentiment:

  • Positive — Compliments, praise, excitement
  • Neutral — Questions, general comments
  • Negative — Complaints, criticism, frustration

This helps you prioritize — negative comments often need faster responses.

Auto-Engage Mode

In Settings, you can enable Auto-Engage. When enabled, the Engage Agent automatically sends replies to positive and neutral comments. Negative comments always require your review.

Sending Replies

  • Click on any comment in the Inbox to see the full context
  • Review the AI-suggested reply
  • Click Send to post the reply, or edit it first
  • The reply is posted directly to the platform via API

Manual Trigger

The Engage Agent runs on a schedule, but you can also trigger it manually from the Inbox page to check for new comments immediately.
